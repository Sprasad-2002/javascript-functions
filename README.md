# JavaScript Functions

This repository contains examples of different types of **JavaScript Functions**.

## Topics Covered

1. **Function Declaration**
   - A normal function defined using the `function` keyword.

2. **Function Expression**
   - A function stored inside a variable.

3. **Arrow Function**
   - A shorter syntax introduced in ES6.

4. **Execution Context**
   - Explains how JavaScript executes functions and manages memory.

5. **IIFE (Immediately Invoked Function Expression)**
   - A function that runs immediately after it is defined.

6. **Arguments Length**
   - Demonstrates how to check the number of arguments passed.

7. **Variable Arguments**
   - Functions that accept multiple arguments using rest parameters.

8. **Function Overloading (Concept)**
   - Demonstrates how JavaScript handles multiple arguments in functions.

## Technologies Used

- HTML
- JavaScript

## Purpose

These examples help understand **how functions work in JavaScript and their different types**.
